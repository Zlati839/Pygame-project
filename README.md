# Pygame project or smh like that
A simple pygame topdown game for now there isnt much just a little terrain generation like water and trees and yea thats all for now just a base line 

## Gameplay 
For now all you can do is destroy the ecosystem by cutting down wood but you can be kind and replant those trees ! 
You get wood and seeds by chopping them down and can get slowed down in water also all trees grow naturally but you can speed that up

## Map generation
Its all random.......

## How to play 
So start the game . Run around and chop trees .
Yea thats all

## Controls 
0 - Make all trees grow 
9 - Plant tree if you have seeds 
e - Cut down trees nearby 
w,a,s,d - walk 
shift - sprint
